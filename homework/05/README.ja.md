# Oak フレームワークを使った個人サイト

課題 5 の要件に沿って、Deno と Oak で作成したシンプルな個人サイトです。

## 動作要件

- Deno がインストールされていること
- deno.land から Oak を取得できるインターネット接続

## 実行方法

1. このディレクトリでターミナルを開きます。
2. 以下のコマンドを実行します。

```
deno run --allow-net personalSite.js
```

3. ブラウザーを開き、`http://localhost:8000` にアクセスします。

## 機能

課題の要件に従って、パスごとに異なる情報を表示します。

- `/name`：氏名
- `/age`：年齢
- `/gender`：性別

そのほかの機能：

- `/`：ホームページ
- `/education`：学歴
- `/interests`：趣味・関心
- `/skills`：スキル
- `/all`：すべての情報を 1 ページに表示

### 多言語対応

サイトは英語と中国語に対応しています。

- URL に `?lang=en` を付けると英語で表示します。
- URL に `?lang=zh` を付けると中国語で表示します。
- 各ページ右上の言語メニューでも切り替えられます。

## 構成

- `personalSite.js`：アプリケーションのメインファイル
- テンプレート関数で統一された HTML ページを生成します。
- すべてのページにナビゲーションリンクがあります。
- 翻訳には対応言語ごとの辞書を使用します。

## 使用技術

- Deno
- Oak ウェブフレームワーク
- 表示用の HTML/CSS
